# Лабораторна робота №4: Взаємодія з БД (Система бронювання)

Четверта практична робота з дисципліни «Сучасні технології розробки WEB-застосувань мовою програмування РНР». **Варіант 8: Система бронювання (готель/зали)**.

## Про проєкт
Проєкт демонструє базові принципи взаємодії PHP-застосунку з базою даних MySQL за допомогою об'єктно-орієнтованого розширення PDO. Головна мета — навчитися підключатися до БД, виконувати CRUD-операції (створення, читання, оновлення, видалення) та надійно захищати застосунок від SQL-ін'єкцій за допомогою підготовлених запитів (Prepared Statements).

## Основні компоненти
- **Виведення даних (SELECT):** Відображення списку всіх зареєстрованих номерів, а також реалізація пошуку за номером кімнати та фільтрації за місткістю.
- **Додавання (INSERT):** Форма для створення нового запису про номер із базовою валідацією введених даних.
- **Редагування (UPDATE):** Форма для оновлення параметрів існуючого номеру (зміни номера, місткості або ціни за ніч).
- **Видалення (DELETE):** Безпечне видалення запису з бази даних за його ідентифікатором (ID).
- **Бібліотека функцій:** Окремий набір підготовлених SQL-запитів до бази даних, винесений в окремий файл для чистоти коду.

## Структура директорій проєкту
- `/schema.sql` — SQL-скрипт створення бази даних `practicum4` та таблиці `rooms`.
- `/db.php` — файл конфігурації та об'єктного підключення до бази даних MySQL через PDO.
- `/functions.php` — файл із допоміжними функціями для виконання SQL-запитів (CRUD-операцій).
- `/index.php` — головний файл, що відображає HTML-таблицю номерів та панель управління/фільтрів.
- `/add.php` — сторінка з формою додавання нового номеру.
- `/edit.php` — сторінка з формою редагування існуючого номеру.
- `/delete.php` — скрипт-обробник для видалення запису з бази даних.
- `README.md` — файл з описом проєкту та інструкцією для запуску.

## Як запустити локально
1. Увімкніть вебсервер **Apache** та сервер баз даних **MySQL** у контрольній панелі XAMPP.
2. Відкрийте phpMyAdmin, створіть базу даних `practicum4` та виконайте код із файлу `schema.sql` (або просто імпортуйте цей файл).
3. Помістіть папку з файлами проєкту у директорію вебсервера (зазвичай це `C:\xampp\htdocs\practicum04`).
4. Відкрийте браузер і перейдіть за адресою: `http://localhost/practicum04/index.php`.

*(Альтернативний запуск: відкрийте термінал у кореневій папці проєкту та запустіть вбудований локальний вебсервер РНР командою `php -S localhost:8000`, після чого перейдіть на `http://localhost:8000/index.php`)*
