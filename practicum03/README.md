# Лабораторна робота №3: Основи ООП (Система бронювання)

Третя практична робота з дисципліни «Сучасні технології розробки WEB-застосувань мовою програмування РНР»[cite: 14].
**Варіант 8:** Система бронювання (готель/зали)[cite: 18].

## Про проєкт
Проєкт демонструє базові принципи об'єктно-орієнтованого програмування (ООП) у PHP. Головна мета — навчитися створювати класи, працювати з об'єктами, використовувати інкапсуляцію та успадкування, а також правильно організовувати структуру коду, виділяючи логіку в окремі файли-бібліотеки[cite: 14].

## Основні компоненти
- **Базовий клас (`Room`):** Описує стандартний номер із базовими властивостями (номер, місткість, ціна за ніч) та методом отримання інформації `getInfo()`[cite: 18].
- **Похідний клас (`ConferenceRoom`):** Успадковує `Room` та розширює його додатковою властивістю `equipmentList` (список обладнання) з перевизначенням методу `getInfo()`[cite: 18].
- **Клас-менеджер (`BookingSystem`):** Зберігає масив об'єктів та реалізує методи для додавання номерів, пошуку вільних кімнат і підрахунку загального очікуваного доходу[cite: 16, 18].
- **Бібліотека функцій:** Окремий набір функцій для форматування діапазону дат та розрахунку кількості ночей між двома датами[cite: 16, 18].

## Структура директорій проєкту
- `/classes/Room.php` — файл базового класу[cite: 16].
- `/classes/ConferenceRoom.php` — файл похідного класу[cite: 16].
- `/classes/BookingSystem.php` — файл класу-менеджера[cite: 16].
- `/lib/functions.php` — файл із допоміжними функціями[cite: 16].
- `index.php` — головний файл, що підключає всі компоненти через `require_once` та генерує HTML-сторінку[cite: 16].
- `style.css` — таблиця стилів для оформлення інтерфейсу.
