# Лабораторна робота №1: Система бронювання

**Варіант 8:** Система бронювання (готель/зали).

## Про проєкт
Це вебсторінка, яка динамічно генерується на стороні сервера засобами PHP. Головна мета проєкту — практичне застосування базового синтаксису PHP: роботи з асоціативними масивами, циклами, умовними конструкціями, функціями, а також навички органічного поєднання PHP-логіки з HTML-розміткою.

## Основний функціонал
- **Відображення даних:** Каталог номерів (із зазначенням номера, місткості та ціни за ніч) виводиться на екран у вигляді стилізованих HTML-карток.
- **Умовна логіка:** Залежно від логічного значення поля `isBooked`, кожен номер автоматично отримує відповідну візуальну мітку: «Заброньовано» (червона) або «Вільний» (зелена).
- **Агрегація даних:** Скрипт самостійно обчислює та виводить підсумковий очікуваний дохід від усіх номерів, які наразі заброньовані.
- **Форматування виводу:** Текст із характеристиками номера формується за допомогою строго типізованої функції `formatRoom()`, яка готує дані до виводу на сторінку.

## Структура проєкту
- `index.php` — головний файл проєкту, що містить вхідні дані (масив масивів), логіку їх обробки та базовий HTML-каркас.
- `style.css` — файл каскадних таблиць стилів, який відповідає за привабливий зовнішній вигляд сторінки (оформлення карток, сітки та підсумкового блоку).

## Як запустити локально
1. Відкрийте термінал у директорії з файлами проєкту.
2. Запустіть вбудований локальний сервер PHP за допомогою команди:
   ```bash
   php -S localhost:8000
3. Відкрийте браузер та перейдіть за адресою: http://localhost:8000.
