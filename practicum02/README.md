# Лабораторна робота №2: Форма бронювання номера

Друга практична робота з курсу «Сучасні технології розробки WEB-застосувань мовою програмування РНР».
**Варіант 8:** Система бронювання (готель/зали).

## Про проєкт
Цей проєкт демонструє взаємодію вебзастосунку з користувачем через HTML-форми, обробку даних на сервері за допомогою PHP (суперглобальний масив `$_POST`), а також реалізацію багаторівневої валідації та збереження стану інтерфейсу[cite: 2].

## Основний функціонал
- **Обробка форми:** Збір даних клієнта (ім'я гостя, номер кімнати, дати заїзду та виїзду)[cite: 2].
- **Серверна валідація (PHP):** Строга перевірка на бекенді. Дата виїзду має бути обов'язково пізнішою за дату заїзду[cite: 2]. Ім'я гостя перевіряється через регулярний вираз (`preg_match`) і може містити лише літери та пробіли[cite: 2].
- **Клієнтська валідація:** Використання HTML5-атрибутів та JavaScript для миттєвої перевірки правильності введених дат перед відправкою на сервер[cite: 2].
- **Локальне сховище (localStorage):** Браузер запам'ятовує останні обрані дати заїзду й виїзду, щоб автоматично підставити їх при наступному відкритті форми бронювання[cite: 2].
- **Безпека:** Захист від XSS-атак за допомогою функції `htmlspecialchars()` при повторному виведенні введених користувачем даних[cite: 2].

## Структура проєкту
- `form.php` — містить HTML-форму, клієнтські скрипти (JS) та PHP-логіку для обробки й серверної валідації даних, а також виведення повідомлень про помилки[cite: 2].
- `style.css` — каскадна таблиця стилів для візуального оформлення інтерфейсу форми.
